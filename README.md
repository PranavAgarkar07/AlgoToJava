# DAA Lab Programs

Java programs for Design and Analysis of Algorithms lab based on Horowitz & Sahni book.

## How to Run

```bash
javac FileName.java
java FileName
```

Need JDK 8 or above. For programs that ask for input, enter values when prompted. Others will directly show output.

## Contents

Programs cover Divide and Conquer, Greedy method and Graph algorithms as per syllabus.

## Note

All programs are written as per textbook pseudocode for lab submission and viva.
